# 巨蟹王城堡保卫战 — 版本记录

游戏 ID：`crab-castle`。线上地址固定为一个页面，首页是版本选择页（`index.html` + `versions.json`），每个版本是 `crab-castle-vN.html`。

- **v1**（2026-11-12）2D 塔防：巨蟹大王守城堡，100 名玩家分 10 波入侵；陷阱（含秒杀）、守卫、超市、枪械、触控开枪。*没有单独保存的文件，只在 artifact 历史版本里。*
- **v2**（2026-11-12）陷阱扩充到 16 种（巨石、捕兽夹、传送门、黄金地砖等）。*没有单独保存的文件。*
- **v3**（2026-11-12）敌人扩充到 21 种（含搞笑角色），分 Lv1–Lv5 装备等级；敌人图鉴。*没有单独保存的文件。*
- **v4**（2026-11-12）`crab-castle-v4.html`：秘籍面板，可直接改金币。2D 的最后一版。无存档。
- **v5**（2026-11-12）3D 大版本（Three.js）：3 张 2.5D 地图、昼夜变化、5 级大王 + 5 个大招、7 种 Boss、14 种兵种（含坦克、机甲、直升机、战斗机）、24 种陷阱、11 个道具、连杀、宝箱、金海鸥、成就、暗号、无尽模式。存档键 `crab3d`（旧格式）。*没有单独保存的文件，只在 artifact 历史版本 1794526159-9e07 里。*
- **v6**（2026-11-13）`crab-castle-v6.html`：所有敌人和守卫换成 3D 骨架模型（走路、攻击、死亡动画），7 个 Boss 专属模型，等级装备 3D 化；300 个以上单位自动简化画法；压力测试按钮；版本号标记和「切换版本」。**存档结构 s1**：`crab-castle/save/s1` = `{ach, map}`，设置移到共用的 `crab-castle/settings` = `{lang, q, sfx, music}`；从 v5 的 `crab3d` 迁移（旧键不动）。
- **v7**（2026-11-13）`crab-castle-v7.html`：地图编辑器（手指画路线、随机路线、主题/难度、分享码导入导出、保存并试玩）；每波结束自动存档，标题页「继续上次」。**存档结构 s2**：`crab-castle/save/s2` = `{ach, mapId, maps, run}`；迁移链 legacy→s1→s2，s1 键不动；启动器支持 s2→s1 降级复制（自制地图和进行中的游戏会丢弃）。
- **v8**（2026-11-13）`crab-castle-v8.html`：四种语言（English / Français / 简体中文 / 繁體中文，标题页和菜单都能切换，所有文字在一张表里，繁体由 OpenCC 转换再按台湾用语修正）；Xbox 手柄（菜单焦点导航、摇杆准星、按住 Ⓐ 开火、Ⓧ 互动、LB/RB 换枪、LT/RT 大招、断开自动暂停、震动、按键颜色提示、电视字号 ≥28px 和 5% 安全区、全屏按钮；地图编辑器用十字键画路线）；开发/作弊/模组面板（`?dev=1`、长按标题螃蟹、菜单）：24 个可调参数、无敌、无限金币、速度 ×0.25–×4、生成 100/1000/5000 敌人、跳过本波、帧率显示、预设保存和 JSON 导入导出，改过参数时顶部显示「已修改」；固定步长 1/60 秒主循环；空间网格（附近敌人查询不再两两比较），5000 个敌人时逻辑约 8 ms/帧（桌面无头 Chrome）；超市卡片重叠的排版问题修好了。**存档结构 s3**：`crab-castle/save/s3` = `{game, schema:3, wid, born, savedAt, ver, ach, mapId, maps, run}`，另有 `/bak`、7 份 `/day-YYYYMMDD`、`/broken-<时间>`、`/copy-backup-<时间>`；迁移链 legacy→s1→s2→s3，旧键都不动；写入前检查 `wid`，发现别处（云端恢复、启动器、另一个标签页）改过就停止写入并请玩家重新加载；备份码 `CRABCASTLE-…`、备份文件、导入（认得 s1/s2/s3/v5 的旧存档）；「上次备份」显示、超过 1 天的提醒、大时刻后提醒；首次空存储先问「以前玩过吗？」；元数据 `crab-castle/meta`，开发参数 `crab-castle/devcfg`，预设 `crab-castle/presets`。启动器：s3 复制进度（含 s3→s2 降级）、「🛟 找回存档」、备份码、手柄操作、四种语言。
- **v9**（2026-11-13）`crab-castle-v9.html`：本地多人。同屏双人（标题页/菜单「👥 同屏双人」）：横屏左右、竖屏上下各一半屏幕，每人同时只跟一根手指，按下的位置决定是谁；可「⇄ 换边」，转屏后座位自动重新分配；每人一张朝向自己的小卡片（颜色、击败数、换枪、暂停）。手柄：第一个用的手柄是 P1，其他手柄按 Ⓐ 加入，最多 4 人（黄/蓝/粉/绿），各自准星、各自的枪和冷却，金币、能量、大王、超市共用；某个手柄断开就暂停并保留座位。结束画面显示每人击败数。所有输入仍然走 `act({type, p, …})`。**存档结构仍是 s3**（和 v8 共用存档，多人设置不存档）。
- **v10**（2026-11-13）`crab-castle-v10.html`：用房间码联机（PeerJS / WebRTC，公共 PeerJS 服务器，最多 4 人，可以和本地多人混着玩）。房主跑游戏逻辑，客人只发动作（`act` 动作带玩家编号），房主检查后执行，每秒 15 次发回状态（对象数组按列压缩，约 2 KB/次）和画面事件；文字以「文字编号 + 参数」发送，每人看到自己的语言。房间码 5 位（无 0/O/1/I/L），可复制码或 `?room=` 链接；连接状态、找不到房间、房间满、版本不同（协议号写在房间 id `crab-castle-n1-CODE` 和握手里）、房主暂停、对方离开（8 秒心跳）、重新连接回同一座位、再来一局都有提示；客人那边用房主的参数并显示「已修改」，客人不会把房主的画面存成自己的进度。claude.ai 页面挡住联网和下载：联机按钮会说明并给出 GitHub Pages 地址；「下载备份文件」在那里改为显示文字让玩家复制。**存档结构仍是 s3**（和 v8、v9 共用）。
